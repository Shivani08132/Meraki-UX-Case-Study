# Meraki-UX-Case-Study

## Overview
Meraki is a mobile application designed to help parents discover, compare, and book trusted after-school care services.

## My Role
UX Designer

## Tools Used
- Figma
- Canva
- Google Forms

## Design Process
- User Research
- Competitive Audit
- Personas
- User Journey
- Wireframes
- High-Fidelity Prototype
- Usability Study

## Key Features
- Search nearby centers
- Filters
- Booking
- Reviews
- Accessibility

## Prototype
https://www.figma.com/proto/fkh2JEUIzJEmsqfS24thsv/Meraki-hi-fi-Prototype?node-id=0-1&t=oOrS8DVP1RKQ9NDO-1

## What I Learned
Working on Meraki strengthened my understanding of the end-to-end UX design process, from identifying user needs through research to creating wireframes, high-fidelity mockups, and an interactive prototype. I learned the importance of designing with empathy, gathering and applying user feedback, and making design decisions based on usability rather than assumptions. This project also improved my proficiency with Figma, enhanced my visual design skills, and reinforced the value of iteration in creating intuitive, accessible, and user-centered experiences.
